# Movie Ticket Booking System

## About the Project

The Movie Ticket Booking System is a command-line Python project that allows users to view movies, check available seats, book tickets, cancel bookings, and view ticket prices.

## Features

- Display available movies
- Display movie genre and rating
- Display available seats
- Book a movie ticket
- Cancel a booking
- Display ticket amount
- Handle invalid user input

## Technologies Used

- Python 3
- Command Line Interface

## Requirements

- Python 3.x
- Command Prompt, PowerShell, or VS Code terminal

## Project Setup

### 1. Download the Project

Download or clone this repository to your computer.

### 2. Open the Project Folder

Open the project folder in Command Prompt, PowerShell, or the VS Code terminal.

### 3. Check Python Installation

Run:

    python --version

If Python is not recognized on Windows, run:

    py --version

### 4. Install Dependencies

This project uses only Python's built-in features.

No external libraries or packages are required.

### 5. Run the Project

Run:

    python movies.py

On Windows, if the above command does not work, use:

    py movies.py

## How to Use

After running the program, the following menu is displayed:

1. Display Movies
2. Display Seats
3. Book Ticket
4. Cancel Ticket
5. Exit
Enter the required option and follow the instructions displayed in the terminal.
